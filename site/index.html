03 — install

One paste.
Any agent.

Copy one block into any agent that can run shell commands. It clones, builds and registers Whale's MCP server and skills — then checks the wallet.

paste into Claude Code 
Install the Whale wallet from https://github.com/jhonnyisaacc/whale

1. Clone it and run: pnpm install --frozen-lockfile && pnpm run build
2. Start the executor in the background with a random token:
   PORT=8788 EXECUTOR_AUTH_TOKEN=<token> pnpm run start:executor
3. Register its MCP server (stdio: node dist/src/mcp-server.js) with
   EXECUTOR_URL=http://127.0.0.1:8788 and the same EXECUTOR_AUTH_TOKEN,
   and the skills in skills/, with this host.

The local MCP is dry-run by default: nothing signs or broadcasts.
Then call wallet_status and show me the result.

Safety

Dry-run by default

Every swap and transfer is a dry-run until you turn live sends on. Self-hosted live, hosted pending.

Caps live in the executor

USD spend caps are enforced server-side. The agent can read them, never raise them.

Never asks for a seed phrase

Keys stay in the signer. No prompt, tool or skill ever requests a mnemonic.

Perps checked before they move

Every perp action passes the signing policy before any is sent. Leverage stops at 3x unless you raise MAX_PERP_LEVERAGE.

Outside text stays outside

RPC failures, Hyperliquid rejections and Bitcoin indexer errors reach the agent in Whale's own words, never the service's text.

Typos fail at boot

SUPPORT_TIERS refuses a chain name it doesn't know, and local live sends obey each chain's tier.
