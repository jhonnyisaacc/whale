chapter 01

Install

Whale runs as an MCP server plus skills. Every host loads the same server and the same skills — only the manifest differs. Start with the one-paste block; it works in any agent that can run shell commands.

1.1One paste, any agent with a shell

paste into Claude Code 
Install the Whale wallet from https://github.com/jhonnyisaacc/whale

1. Clone it and run: pnpm install --frozen-lockfile && pnpm run build
2. Start the executor in the background with a random token:
   PORT=8788 EXECUTOR_AUTH_TOKEN=<token> pnpm run start:executor
3. Register its MCP server (stdio: node dist/src/mcp-server.js) with
   EXECUTOR_URL=http://127.0.0.1:8788 and the same EXECUTOR_AUTH_TOKEN,
   and the skills in skills/, with this host.

The local MCP is dry-run by default: nothing signs or broadcasts.
Then call wallet_status and show me the result.

1.3Hosted gateway

No clone. A client with MCP OAuth needs only the URL; others send an agent key as Authorization: Bearer whale_…. Sends through the gateway are dry-run during beta.

claude mcp add --transport http whale https://app.mywhalewallet.com/mcp

Defaults are safe. The local MCP is dry-run by default. Spend caps live in the executor, and no step ever asks for a seed phrase.

chapter 05

Safety model

What stops a send, and where in the code it happens. Each line links to the code on main at the commit this page was checked against.

Dry-run by default
Swap, transfer, perp and send_bitcoin plan and sign nothing unless the caller asks for live, and live needs whale-signer, whose refusal is final. Hosted sends stay dry-run until hosted live opens.mcp-server.ts:31 · gateway/mcp-tools.ts:113
USD caps in the executor
Live sends are priced and counted against per-trade and daily USD caps. Hosted wallet_status reports what is left today as remainingTodayUsd.gateway/mcp-tools.ts:115 (#149)
A sent BTC spend keeps counting
If the spend journal fails to commit after a Bitcoin send, the row stays reserved with its txid, so reconciliation can finish it. A TLA+ model checks the spend_journal cap across restarts and retries.bitcoin/send.ts:50 (#173, #192) · SpendCap.tla (#199)
Perps
Read positions, margin, funding and open orders. Every perp action is checked before any is signed or sent. The signing policy refuses leverage above MAX_PERP_LEVERAGE, 3 by default. When the signing key trades for another account, Whale first checks it is an approved agent of that account.broadcast.ts:32 (#190) · signing-policy/hypercore.ts:85 · config/load.ts:87 (#143) · hyperliquid.ts:133 (#195)
Native Bitcoin
Hold, receive and send BTC under the same USD caps. send_bitcoin pays only addresses in BITCOIN_WITHDRAW_ADDRESSES. No tool trades BTC.bitcoin/send.ts:88 (#155)
Bridges
Both signers can sign a live LI.FI AcrossV4 bridge under a decoding rule, but no MCP tool or CLI command executes a bridge yet. The bridge tool ranks quotes and never broadcasts.signing-policy/bridge-terms.ts:25 (#182) · commands.ts:143
Outside text stays outside
RPC failures, Hyperliquid rejections and Bitcoin indexer errors reach the agent in Whale's own words. A rejection in an unknown form reads “reason not in a known Hyperliquid format” or “reason not in a known bitcoind format”.rpc-reason.ts:60 (#193) · hyperliquid.ts:352 (#178) · esplora.ts:97 (#204)
Support tiers
SUPPORT_TIERS refuses a chain name it doesn't know at boot. Local live sends obey each chain's tier: zkSync defaults to dry-run and Monad to disabled.support.ts:20 (#189) · local-sends.ts:94 (#177) · support.ts:6
Base, Optimism and Scroll in the enclave
The hosted Turnkey policy renders their L2 gas clause, so an enclave wallet reaches them after its owner re-runs delegation. Blast still gets no clause.signing-policy/turnkey.ts:83 (#194)
No seed phrase, ever
Keys stay in the signer. No prompt, tool or skill asks for a mnemonic.
How it is checked
pnpm run check runs the build and the tests. The verify-whale skill drives the MCP server, the CLI and the executor in dry-run. A test keeps every tracked file clear of the Hermes install scan's high and critical patterns.verify-whale (#198) · host-manifests.test.ts:201 (#200)
