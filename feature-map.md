# Feature map

Each row names a feature and the check that proves it. Add a row when a feature moves.

| --- | --- |
| Quote, swap, bridge, balance, and transfer share one command union | `pnpm test`. `test/commands.test.ts` covers the dispatcher. |
| A dry-run swap quotes a signable route or names why it skips, and never signs or broadcasts. A quote with no provider skips | `pnpm test`. `test/dry-run-swap-quotes.test.ts` stubs aggregator HTTP. The command and executor tests cover the rest. |
| Bridge routes are fetched from LI.FI, Across, and Relay, ranked by fee, refused off the owner allowlist or enabled chains, and never broadcast | `pnpm test`. `test/bridge-routes.test.ts` stubs provider HTTP. The command and controls tests cover the planner. |
| `perp_positions` reads Hyperliquid margin, positions, funding, mark, and open orders, tells limit orders from stop, take-profit, and trailing-stop triggers, reads a fired stop that still rests as a limit, shows a position TP/SL as covering the whole position, lists an order of unknown shape as unreadable without hiding the positions, and refuses any other `info` response of unknown shape | `pnpm test`. `test/perp-state.test.ts` replays captured mainnet `info` responses. |
| A LI.FI AcrossV4 or Across bridge is screened on both chains, reserved, simulated with its approval, bound by the signing policy and whale-signer to this wallet or an allowlisted destination on another enabled chain, to the same token at no more than `MAX_BRIDGE_FEE_BPS` below the charge with no exclusive relayer, and held signed while broadcast is off. Relay stays quote-only | `pnpm test`. `test/bridge-policy.test.ts` and `test/bridge-execute.test.ts` use real provider calldata in `test/fixtures/bridge`. `cargo test` in `signer/` runs the same calldata as vectors. `node scripts/bridge-live-proof.mjs` signs a real 2 USDC Base to Arbitrum Across route and the live LI.FI quote, and simulates both on Base. `node scripts/bridge-decode-check.mjs` fails when either signer refuses a live LI.FI bridge quote. `node scripts/verify-bridge-contracts.mjs` checks every listed contract and bridge token on chain and against Across's route list. |
| Live send is screened, simulated, reserved, and policy checked | `pnpm test`. The send-path and security-review tests cover it. |
| Withdraw needs the admin token, the allowlist, and the per-call cap | `pnpm test`. The custody and controls tests cover it. |

With `WHALE_BROADCAST` unset the signed job is reported and not sent | `pnpm test`. `test/whale-signer.test.ts`, `test/hypercore-whale-signer.test.ts`, and the held-send case in `test/send-path.test.ts`. |
| The self-hosted Rust signer refuses anything outside its local policy, checks 0x and Kyber swap recipients and daily totals, and signs bytes identical to viem and node:crypto | `cargo test --locked` in `signer/`, run by the `signer` CI job. `test/signer-vectors.test.ts` keeps the app decoder in step. |
| A hosted swap is priced by what it sells and a transfer by what it moves: stablecoins at par, any other token by Whale's own quotes into the chain's dollar asset, taking the larger of the whole amount and a thousandth of it scaled up. Only above an approval threshold the owner set does it wait for a passkey approval of that exact command, which expires in an hour and is spent once the executor answers. The agent lists and cancels its own open requests, and an expired request leaves the pending list on its own. Activity lists refusals too | `pnpm test`. `test/gateway-mcp-pg.test.ts`, `test/gateway-sends-pg.test.ts`, and `test/gateway-requests-pg.test.ts` with `TEST_DATABASE_URL`. |
| Network costs rank chains by a live swap and transfer estimate, fall back to the static ceiling when a read fails, and cache for 30 s; an x402 option fits only when the hosted transfer path would allow the same payment and it stays inside the agent's and the wallet's USD caps, and nothing is paid | `pnpm test`. `test/network-costs.test.ts`, and `test/gateway-x402-pg.test.ts` with `TEST_DATABASE_URL`. |
